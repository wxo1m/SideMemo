# SideMemo 웹 안정성 검사 체크리스트

웹사이트 전용 실행·데이터 무결성 검사다. 데스크톱 `docs/stability-review-checklist.md`를 대체하지 않는다. 매번 현재 커밋과 미커밋 변경을 기록하고, 브라우저 테스트는 로컬 격리 페이지·모의 서버로 실행한다. 실제 계정, 개인 메모, 운영 DB를 변경하지 않는다. 결과는 `stability-reviews/YYYY-MM-DD-web-review.md`에 기록한다.

- WEB-ST-01 JavaScript 구문과 필수 웹 파일을 확인한다.
- WEB-ST-02 메모 편집, 한글·서식·목록, 새로고침 전 편집 반영을 검사한다.
- WEB-ST-03 로그인/로그아웃/세션 복원 중 빈 메모가 잘못 생성되거나 남지 않는지 확인한다.
- WEB-ST-04 읽기 실패·오프라인·권한 오류를 빈 서버 데이터와 구분하고 자동 업로드하지 않는지 검사한다.
- WEB-ST-05 업로드 중 수정이 완료 처리되지 않고, 실패한 업로드를 성공으로 표시하지 않는지 확인한다.
- WEB-ST-06 원격 데이터 수신·계정 전환 도중 응답이 계정 간 섞이지 않는지 검사한다.
- WEB-ST-07 원격 메모의 형식·크기 검증과 첨부 형식 제한을 확인한다.
- WEB-ST-08 저장형 HTML, 붙여넣기, 위험 요소 정화가 일반 서식을 보존하는지 확인한다.
- WEB-ST-09 릴리스 버전, CDN 로딩, 작은 화면/실제 브라우저 제공은 로컬 모의와 실제 배포 검증을 구분한다.

각 항목을 `통과 / 실패 / 미검증 / 해당 없음`으로 판정하고 재현 근거와 범위를 결과 보고서에 기록한다. 로컬 테스트는 실제 Supabase 권한이나 공개 Pages 배포를 입증하지 않는다.
