# SideMemo 안전성·안정성 검사 체크리스트

보안 체크리스트와 별도로 실행 안정성 및 데이터 보존을 검사한다. 매번 현재 커밋과 미커밋 변경을 기록하고 실제 구현 함수를 사용한다. 통과/실패/미검증/해당 없음과 검사 범위를 명시한다. 모의 검사를 실제 설치·서버 검사로 표현하지 않는다.

운영 메모·계정·자동 시작·트레이 상태를 변경하지 않는다. 격리 데이터와 임시 폴더, 모의 네트워크를 사용한다. 실패를 발견해도 검토 요청만으로 코드 수정·배포하지 않는다. 보고서는 `stability-reviews/YYYY-MM-DD-review.md`에 저장한다.

- ST-01 문법/모듈: Python·JS 구문, Qt 모듈 로딩 및 필수 파일 확인.
- ST-02 시작/종료: 신규·재실행·중복 실행·트레이·종료 중 저장·동기화 안전성. 실제 GUI 검증 여부 구분.
- ST-03 저장 왕복: 한글·서식·커스텀 색·순서·삭제 기록 저장/재읽기 일치.
- ST-04 손상 데이터: 손상 JSON/스키마/계정 파일에서도 원본 보존 및 복구 안내. 초기값 덮어쓰기 금지.
- ST-05 저장 실패: 권한/디스크 부족/쓰기 중단 시 이전 메모 유지 및 실패 안내. 세션과 본문 모두 확인.
- ST-06 계정 전환: A/B/local 분리 및 복원, 전환 중 동기화 차단, 기존 데이터 이전/복구 경로.
- ST-07 인증 장애: 만료 갱신/재시작, 갱신 거절·네트워크·429·5xx 후 올바른 재시도와 상태.
- ST-08 동시 편집: 전송 도중 수정이 미전송 상태로 유지되며 서버 응답이 새 편집을 지우지 않음.
- ST-09 최초 동기화: Qt 빈 문서도 빈 것으로 판정, 기존 서버 메모 채택, 오류를 빈 데이터로 간주하지 않음.
- ST-10 웹 편집: 새로고침·붙여넣기·서식·목록·첨부·빈 상태·한글 입력·오프라인 복귀. sanitizer 변경 후 호환성 포함.
- ST-11 백업/복구: 정상 왕복, 손상/부분 복구/용량 초과 시 원본 보존.
- ST-12 배포/화면: EXE와 설치 파일 버전/런타임, Python 없는 PC 설치·제거, 좌우/다중 모니터/DPI/최소 크기.

보고서에는 항목별 결과, 재현 명령/근거, 사용자 영향, 권고, 미검증 사유와 개수를 기록한다. 기존 실패는 재검사로 해소될 때까지 유지한다.
