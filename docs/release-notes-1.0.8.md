# SideMemo 1.0.8 (Pre-release)

## 주요 변경 사항
- **로그인 유지 오류 수정**: 갱신된 세션을 즉시 저장하여 재시작 후에도 유지합니다. 세션 만료를 비밀번호 오류로 표시하던 문제를 수정했으며, 네트워크 오류 시 로그인 정보를 보존합니다.
- **기본 Supabase 접속 정보 내장**: 설정 창에서 Supabase Project URL과 anon key를 직접 입력하지 않아도 바로 로그인 및 회원가입하여 동기화 기능을 사용할 수 있습니다.
- **웹 클라이언트 연동 최적화**: 웹 클라이언트에서도 연결 설정 단계를 제거하고 즉시 로그인하여 사용할 수 있도록 개선되었습니다.
